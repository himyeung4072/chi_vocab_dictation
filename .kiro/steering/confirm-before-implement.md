用戶提出新要求、修改或回報問題時，必須先複述，確認後才實作。

1. 用香港繁體中文以自己的話複述：目標、範圍（會改邊度，如已知）、不會做的事（不順便改動的項目）、不清楚處（假設／疑問，請用戶決定）。
2. 複述後停低，問「我理解啱唔啱？」，等用戶回覆。
3. 用戶明確確認（如「啱」、「確認」、「可以」、「做啦」）後才實作。
4. 用戶糾正則修正後再複述，直至確認。

確認前禁止：改／新增／刪除檔案、啟動 workflow（含 `run_workflow`）、執行改變狀態的指令（如 git commit、安裝依賴）。
確認前允許：回答問題或解釋；為令複述準確而做最少量唯讀查證（如確認路徑）。

例外：純發問、討論、分析（無改動要求）免複述；用戶明示「唔使確認，直接做」可直接實作。
